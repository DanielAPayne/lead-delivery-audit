Lead Delivery Audit

Matching totals can hide lost leads. Load the ad-form export, the automation's run log and the CRM export, and every submission is traced by its ID to the last step that recorded it.

Files are read in this page only. Nothing is uploaded, and only ID and time columns are used.

Your exports

CSV, TSV or JSON Lines. Drop a file on a box or choose one. Check the ID column each file should be matched on.

1. Source

Ad-form submissions, for example a Meta Leads Center download.

2. Router (optional)

Automation runs from n8n, Zapier or Make. Needed to locate a break.

3. CRM

CRM rows that carry the original submission ID, such as a HubSpot export.
